

# 🏦 Simulador de Conta Bancária em Java

Aplicação de console desenvolvida em Java para simular as operações básicas de uma conta corrente, praticando controle de fluxo, entrada de dados e formatação de strings.

## ⚙️ Funcionalidades
- **Consulta de Saldo:** Exibe o valor atual disponível na conta formatado em reais.
- **Transferência de Valores:** Valida se o saldo é suficiente e impede transferências de valores negativos ou zerados.
- **Recebimento de Valores (Depósito):** Adiciona valores válidos ao saldo atual.
- **Menu Interativo:** Mantém a execução ativa até que o usuário escolha a opção de sair.

## 🛠️ Tecnologias e Conceitos Utilizados
- **Java (JDK 25)**
- Estruturas de repetição (`while`) e decisão (`switch-case`, `if/else`)
- Leitura de dados via console com `java.util.Scanner`
- Formatação de textos e casas decimais com **Text Blocks** e `.formatted()`
